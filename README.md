# Portfolio Sample API

This is a Flask API demo fetching real-time weather data from OpenWeatherMap
and mock JSON data from JSONPlaceholder. The project is built with AI-assisted scaffolding
to demonstrate backend development concepts.

## Features

- Fetch weather data for a given city
- CRUD operations using JSONPlaceholder
- AI-assisted endpoint scaffolding
